SAHRA's custom icon set — one uniform 1.6px line weight. The signature family is drawn from Cairo dining culture: `tea` (istikan glass), `mezze` (shared plate), `lantern`, `shisha`. Matching UI glyphs (search, heart, user, map-pin, clock, calendar, check, spark…) share the same hand. Unknown names fall back to Lucide.
```jsx
<Icon name="lantern" size={22}/>
<Icon name="tea" size={20} style={{color:'var(--terracotta)'}}/>
```
Inherits color from `currentColor`. Use `spark` for gold/celebratory moments.
